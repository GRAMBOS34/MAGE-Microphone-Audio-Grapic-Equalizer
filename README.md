## Installation

1. Clone this repo with:

```
git clone https://github.com/GRAMBOS34/MAGE-Microphone-Audio-Grapic-Equalizer.git
```

2. Go into the directory and install the prerequisites using pip:

```
pip install -r requirements.txt
```

3. With the terminal open in the working directory, run `main.py` to launch the program:

```
python main.py
```
